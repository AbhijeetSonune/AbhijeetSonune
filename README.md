<summary>🏥 <b>Healthcare Patient Wait-Time Analysis</b> — Python · SQL · Seaborn</summary>
<br>

> EDA + SQL project identifying bottleneck OPD departments and peak-day congestion in a hospital setting.

**Key Findings:**
- Neurology & Cardiology have highest avg wait times
- Monday & Wednesday are peak congestion days
- Walk-in patients wait **35% longer** than appointment patients
- Satisfaction drops sharply when wait exceeds **60 minutes**

**Outputs:** 6-panel visualisation · Cleaned dataset · Recommendations report

</details>

<details>
<summary>📦 <b>E-Commerce Returns Root Cause Analysis</b> — Python · SQL</summary>
<br>

> SQL + Python project finding what drives product returns across 2,000 orders.

**Key Findings:**
- Electronics has the highest return rate (~40%)
- Slow delivery (>10 days) leads to ~55% return rate
- Top reasons: Wrong Size & Defective Product
- Festival months spike returns by ~40%

</details>

<details>
<summary>💼 <b>HR Attrition Analysis & Dashboard</b> — Python · SQL</summary>
<br>

> HR analytics project on 1,500 employee records to find who leaves and why.

**Key Findings:**
- Overtime employees are **2× more likely** to leave
- Employees earning <₹25K have ~45% attrition rate
- First 2 years = highest risk window for early attrition
- Low satisfaction + low work-life balance → >55% attrition

</details>

<details>
